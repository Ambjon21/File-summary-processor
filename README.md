# 📊 Data File Processor & Summarizer

An interactive web application built with Python and Streamlit that simplifies data inspection, automated data cleaning, summary statistics, and visual reporting for uploaded CSV and Excel files.

## Features
- **Multi-Format Upload:** Supports `.csv`, `.xlsx`, and `.xls` files.
- **Quality Checks:** Automatic detection of row count, column structure, missing values, and duplicate records.
- **Interactive Visuals:** Dynamic histograms and bar charts powered by Plotly.
- **Automated Export:** Option to remove duplicate rows and download a cleaned CSV report.

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly Express
